# 挂机锁（idle-lock）

个人站 `/idle` 挂机页的**本机**锁定工具（仅 Windows）。挂在挂机页上时，
点「退出挂机」会弹出全屏密码锁并拦截 `Win` / `Alt+Tab` / `Alt+F4` / `Ctrl+Esc`
等逃生键，输入正确密码后才解锁并退出。

## 它怎么和网页联动

网页进入挂机页时会探测本机 `http://127.0.0.1:38472/ping`：

- **探测到**（本工具正在运行）→ 点「退出挂机」会先请求 `/lock`，本工具弹全屏
  密码锁；未解锁前网页一直挂起，解锁后才跳转离开挂机页。
- **探测不到**（手机、别的电脑打开网页）→ 按正常流程直接退出，与本工具无关。

挂机页左上角会显示 `本机锁已连接` / `本机锁未启动`，方便确认探测结果。

## 用法

1. 确认已装 Python 3（本机 3.13 即可，用系统自带 `tkinter`，无需装第三方库）。
2. 把密码写进 `password.txt`（本仓库已忽略此文件，不会提交）：
   ```
   rr070502
   ```
3. 双击 `start-idle-lock.bat` 启动（会留一个控制台窗口，关掉即停止工具）。
4. 打开挂机页，左上角出现 `本机锁已连接` 即生效。

想开机自启：给 `start-idle-lock.bat` 建个快捷方式，丢进
`shell:startup`（Win+R 输入即可打开启动文件夹）。

## HTTP 接口（都只监听 127.0.0.1，不对外网开放）

| 路径 | 说明 |
| --- | --- |
| `GET /ping` | 探测用，返回 `{"app":"idle-lock","ok":true,"version":1}` |
| `GET /status` | 返回 `{"locked":bool}` |
| `GET /lock` | 弹锁并挂起，解锁（密码正确）后返回 `{"ok":true,"unlocked":true}` |

## 边界与注意

- 这是**软锁**：密码在本地 `password.txt` 里，作用是「防他人随手操作电脑 / 防误触」，
  不是抗破解的安全边界。
- 锁定时唯一的出路是输入正确密码，或用 `Ctrl+Alt+Del` 打开任务管理器结束本进程。
  `Ctrl+Alt+Del` 是操作系统保留的安全通道，任何程序都拦不住——这也是刻意的兜底，
  万一密码忘了不至于把电脑彻底锁死。
- 只在**主显示器**铺满全屏；多屏时其他屏幕仍可见桌面。
- 本工具是 Windows 专用（用了 Win32 键盘钩子与 Tk 全屏窗）。
