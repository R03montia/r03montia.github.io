本站基于 Astro 构建，静态输出，部署在 GitHub Pages。

## 版式

视觉上参考了trauma版式的极简思路：浅灰底、白色半透明卡片、底部城市剪影，外加雨天氛围层。

我喜欢这个版式，它被改造为适配博客站的潜力比废年要高。

本来是打算trauma做首页而废年做博客页版式的，但是惊奇的发现trauma对博客页也有相当好的适配性……哈啊废话，本来就是用来承载文章的版式。

总之，目前全局都使用类trauma作为版式。

## 部署

push 到 main 分支即自动构建发布，全程无服务器。
